# FAKE NEWS DNA TESTER

### An AI-Powered Multimodal and Multilingual Misinformation Investigation Platform for India

## About the Project

Fake News DNA Tester is an academic project focused on investigating potentially misleading information across text, images and videos.

The platform aims to analyse claims, retrieve supporting evidence, examine source credibility, identify rhetorical patterns and generate an explainable Misinformation DNA Report.

Rather than relying only on a binary fake-or-real classification, the system aims to provide claim-level findings with supporting evidence, source references and limitations.

## Key Features

- Text-based misinformation investigation
- Image text extraction and analysis
- Video frame and audio analysis
- Multilingual processing
- Claim extraction and verification
- Evidence retrieval and source tracing
- Explainable Misinformation DNA Reports

## Six Diagnostic Modules

1. Claim Extraction
2. Credibility Scoring
3. Emotional Manipulation Detection
4. Logical Fallacy Scanning
5. Source and Author Analysis
6. Contextual Bias and Framing Analysis
