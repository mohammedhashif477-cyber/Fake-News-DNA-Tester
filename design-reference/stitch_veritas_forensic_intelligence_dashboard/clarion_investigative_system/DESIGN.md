## Brand & Style

This design system serves as an investigative intelligence platform tailored for verifying digital claims, dubious media, and viral forwards. The brand aesthetic merges the disciplined precision of modern devtools (Linear) with the calm readability of answer engines (Perplexity). It strips away the paranoia and visual alarmism often found in security dashboards in favor of composure, clarity, and authority.

The aesthetic philosophy is **Minimal Technical Humanism**:
- **Composed Authority:** Clean dark surfaces that ensure optimal nighttime or low-glare readability during dense investigative sessions, paired with surgical cyan cues.
- **Cognitive Safety:** Zero fluorescent glow clutter, alarming red alerts, or sensor-overload animations. Statuses communicate facts clearly rather than provoking emotional panic.
- **Approachable Utility:** Complex verification traces, forensic timelines, and provenance trails are framed in clear, highly legible natural language suited for multi-generational and non-technical users verifying everyday messaging app rumors.

## Colors

The palette is engineered specifically for deep focus, prolonged viewing, and unambiguous cognitive categorization on dark displays.

- **Canvas Foundation (`#0F172A`):** A tinted dark background with subtle blue-slate undercurrents that prevents harsh contrast fatigue.
- **Surface Elevation (`#1E293B`, `#334155`):** Cool-toned slate containers creating structured, low-strain planar hierarchy without reliance on heavy shadows.
- **Primary Accent (`#06B6D4`):** Electric Cyan serves as the focal point for primary interactions, query triggers, confidence anchors, and active investigative paths.
- **Secondary Accent (`#8B5CF6`):** Soft Purple denotes deep-learning inferences, automated synthetic media analysis, and semantic relation graphs.
- **Validation Signals:** 
  - Verified True / Safe: Jade Emerald (`#10B981`)
  - Debunked / Manipulated: Rose Crimson (`#F43F5E`)
  - Inconclusive / Context Missing: Amber Ochre (`#F59E0B`)
- **Neutral Boundaries & Hierarchy:** Outlines use `#334155` for primary surface separation and `#475569` for interactive element borders. Body copy relies on high-legibility slate-gray (`#94A3B8`) and light high-contrast headers (`#F8FAFC`).

## Typography

The typography pairings strike a deliberate balance between friendly legibility and technical rigor:

- **Display & Headings (Plus Jakarta Sans):** Rounded terminals and wide geometric apertures make verification verdicts feel human, approachable, and free of bureaucratic intimidation.
- **Narrative & Claims (Inter):** Highly legible vertical metrics, neutral tracking, and expansive line heights (1.65 - 1.875) ensure non-native English users and users reading long-form context summaries experience minimal reading friction.
- **Metadata & Technical Evidence (JetBrains Mono):** Reserved for cryptographic hashes, timestamps, EXIF data strings, and source URL provenance.

## Layout & Spacing

The layout model is a disciplined fluid grid anchored to a standard 8px visual cadence (with 4px micro-steps).

- **Grid Architecture:** 12-column layout for desktop views (max-width `1280px` centered), 8-column layout for tablets (`768px` to `1024px`), and a single fluid column layout for mobile (`<768px`).
- **Investigative Split-Pane:** On desktop, primary claim investigation splits 65/35: the left workspace hosts the claim timeline and evidentiary synthesis, while the right rail serves real-time source citations and reverse-search image metadata.
- **Breathing Room:** Dense forensic metadata is offset by generous canvas margins and macro card spacing (`space-lg` to `space-xl`), preventing visual overwhelm for non-technical users.

## Elevation & Depth

Visual hierarchy rejects garish neon glows, excessive layered dropshadows, and skeuomorphic bevels. Instead, depth is established strictly through **Tonal Surface Stacking** and **Subtle Structural Outlines**:

- **Level 0 (Canvas Base):** Solid `#0F172A`.
- **Level 1 (Default Containers & Feed Cards):** `#1E293B` enclosed with a crisp, low-contrast 1px border of `#334155`. Subtle shadow: `0 1px 3px 0 rgba(0, 0, 0, 0.3)`.
- **Level 2 (Active Analysis Modules, Hover States & Side Rails):** `#334155` with an elevated border tone of `#475569`.
- **Level 3 (Modals, Context Overlays & Dropdowns):** `#1E293B` with an ultra-diffused clean ambient shadow: `0 16px 36px -8px rgba(0, 0, 0, 0.5)` and a top border highlight.
- **Interactive Focus:** Input focus and active selections avoid radiant outer glows, using instead a crisp `1.5px` border transition to `#06B6D4` paired with an offset outline of `rgba(6, 182, 212, 0.25)`.

## Shapes

The interface embraces a tailored Level 2 roundedness (`rounded-md: 0.5rem`, `rounded-lg: 0.75rem` / 12px, `rounded-xl: 1rem` / 16px):

- Standard investigative cards, media query zones, and input containers use clean 12px–16px radii, providing a modern, friendly contour that softens analytical tension.
- Action tags, source attribution pills, and credibility badges utilize complete pill radiuses (`rounded-full`) to immediately distinguish categorical indicators from structural content cards.
- Embedded media (video snippet checks, image crops) share the uniform 12px radius with an inner inset ring (`inset 0 0 0 1px rgba(255, 255, 255, 0.06)`).

## Components

### Buttons
- **Primary:** Solid `#06B6D4` background, dark text `#0F172A`, font-weight 600, height 40px (desktop) / 44px (touch target), 10px corner radius. Subtle hover shift to `#22d3ee`.
- **Secondary:** Surface container `#334155`, 1px border `#475569`, text `#F8FAFC`. Active state transitions border to `#06B6D4`.
- **Ghost / Utility:** Transparent background, text `#94A3B8`, hover background `#334155` with text `#F8FAFC`.

### Claim Verification Input (Search / Paste Bar)
- Oversized input module (56px height) with `#1E293B` fill, 16px border-radius, and 1px border `#334155`.
- Features unified drag-and-drop support for screenshots/forwards, inline media paste detection, and a distinctive cyan execution button labeled "Investigate Forward".

### Verdict Badges & Status Chips
- Pill-shaped (`rounded-full`), height 28px, 12px horizontal padding.
- Semi-transparent background (15% opacity) paired with solid text and an SVG indicator:
  - **False / Fabricated:** Background `rgba(244, 63, 94, 0.15)`, text `#FB7185`, border `1px solid rgba(244, 63, 94, 0.3)`.
  - **Verified Genuine:** Background `rgba(16, 185, 129, 0.15)`, text `#34D399`, border `1px solid rgba(16, 185, 129, 0.3)`.
  - **Lacks Context:** Background `rgba(245, 158, 11, 0.15)`, text `#FBBF24`, border `1px solid rgba(245, 158, 11, 0.3)`.

### Investigation Cards
- Built on `#1E293B` with 16px radius and 1px `#334155` border.
- Header features the claim source and timestamp, followed by a bold natural-language claim breakdown, an expandable evidence drawer, and verified primary-source pill citations linking directly to authoritative fact checks.

### Form Controls & Checkboxes
- Selection boxes use 6px rounded squares filled with `#334155` and a 1px border `#475569`. Checked states activate with a `#06B6D4` fill and sharp dark checkmark glyph.

### Domain-Specific Components
- **WhatsApp Forward Unpacker:** An import card styled with a muted dark-slate tint (`#064e3b` with low opacity) providing immediate side-by-side breakdowns: *Original Forward Content* vs. *Fact-Checked Reality*.
- **Confidence Meter:** A quiet, non-gamified horizontal track (4px height) with segmental ticks displaying automated source consensus without sensory overload.
